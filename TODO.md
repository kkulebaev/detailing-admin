## Клиенты / удержание

### 3.2. Карточка клиента с историей визитов и авто
Клик по клиенту на `/clients` → все его записи, машины, суммарно потрачено, дата последнего визита.

- **Ценность:** `/clients` показывает контакт и машины, но не историю. Мастер на телефоне не видит, что клиент уже приезжал и на что.
- **Сложность:** M — диалог/страница + новый роут «записи клиента».
- **Тех. заметки:** только Postgres (`bookings.clientId`, `clientCars`). Индекс `bookings_client_id_idx` уже есть — запрос дешёвый. Sheets не трогаем.

## UX формы записи

### 5.1. Автоподстановка клиента и его авто по телефону
При вводе телефона в форме записи подтягивать имя и список машин уже известного клиента.

- **Ценность:** повторный клиент вводится заново; растут опечатки в имени/авто и дубли в данных.
- **Сложность:** S–M — в форме уже есть работа с телефоном; нужен lookup-запрос по нормализованному номеру.
- **Тех. заметки:** Postgres (`clients` uniq по phone, `clientCars`). `normalizePhone` уже даёт E.164 для поиска. На запись в Sheets не влияет.

### 5.2. Экспорт записей/клиентов в CSV
Кнопка «Экспорт» на `/bookings` и `/clients` с учётом текущих фильтров.

- **Ценность:** данные из Postgres-зеркала нельзя выгрузить для бухгалтерии/анализа вне Sheets.
- **Сложность:** S — сериализация уже отфильтрованной выборки; фильтры на `/bookings` готовы.
- **Тех. заметки:** Postgres, только чтение. Помнить про кодировку кириллицы — UTF-8 BOM для корректного открытия в Excel.

## Автоматизация / уведомления

### 4.1. Напоминание клиенту о записи (день до)
Автоматическое напоминание клиенту накануне визита.

- **Ценность:** сейчас уведомляется только мастер (Telegram). Клиент ничего не получает → неявки (статус «Не приехал»).
- **Сложность:** L — нужен внешний канал; телефоны только `+7`, у клиента нет Telegram → потребуется SMS/WhatsApp-провайдер, шедулер, шаблоны, отписка.
- **Тех. заметки:** Postgres как источник расписания + внешний воркер/cron. **Критично:** не встраивать в `POST /api/bookings` синхронно и не гейтить запись — инвариант «не терять запись».
- **Открытые вопросы:** канал и бюджет (SMS-провайдер / WhatsApp Business), нужно ли согласие на рассылку и отписка.
